Built to stay out of your way

A coherent local foundation for applications that need durable, queryable data.

Documents are truth

Each document is one canonical JSON file. Inspect it, back it up, and rebuild every derived index from it.

Zero-payload indexes

Sorted prefix keys narrow a query without duplicating document payloads or becoming a second source of truth.

SQL + structured queries

Use SQL or the document API over one engine, with exact, range, prefix, and trigram access paths.

One self-contained binary

No daemon or native add-on. Every shim can select an application.json, so independently configured roots can share one application.

Serverless without a broker

Durable topics, consumer groups, visibility leases, retries, dead letters, and bounded SDK decorators live beside the data.

Encryption & POSIX access

AES-GCM fields, HMAC blind indexes, and POSIX UID/GID/mode enforcement keep confidentiality and authorization explicit.
