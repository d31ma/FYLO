Explicit configuration

Settings in JSON.
Secrets stay separate.

Configure the native engine in application.json. Everything lives under fylo, with nested keys for related settings.

Keep only secrets in an adjacent .env file or your secret manager. Reference them from JSON; environment variables no longer implicitly configure FYLO.

Read the configuration guide →
02 / application.jsonNative engine 
{
  "fylo": {
    "root": "./data",
    "shard": { "width": 1 },
    "encryption": {
      "key": "${FYLO_ENCRYPTION_KEY}"
    },
    "cipher": {
      "salt": "${FYLO_CIPHER_SALT}"
    }
  }
}

Encryption is optional. Omit both encryption and cipher if you do not need it.
